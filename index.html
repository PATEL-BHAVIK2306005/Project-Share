🎓 B.Tech CSE Viva-Voce Master Guide: Essential questions and model technical answers to ace your laboratory evaluation.
Q1 What is Flask and how does it handle request routing?
+
Task 1: Architecture
Flask is a lightweight Python WSGI microframework based on Werkzeug and Jinja2. Routing is handled via route decorators like @app.route('/path', methods=['GET', 'POST']). When an incoming HTTP request hits the WSGI server, Werkzeug matches the URL rule against registered endpoints and dispatches it to the corresponding Python view function.
Q2 What is the purpose of Jinja2 Template Inheritance?
+
Task 1: Template Engine
Template inheritance enforces the DRY (Don't Repeat Yourself) principle. A centralized master skeleton (base.html) defines the navigation bar, stylesheets, scripts, and footer. Child templates extend it via {% extends "base.html" %} and override isolated content blocks ({% block content %}), drastically reducing code redundancy.
Q3 How does the application connect to MySQL in XAMPP?
+
Task 3: Database Layer
The application uses Flask-SQLAlchemy with the PyMySQL DBAPI driver. The URI is mysql+pymysql://root:@localhost:3306/majestic_db. Furthermore, config.py implements a zero-downtime resilience check: if XAMPP MySQL is unreachable, it automatically falls back to local SQLite (pbl_framework.db) to prevent evaluation crashes.
Q4 Why is password hashing critical, and which algorithm is used?
+
Task 2: Authentication Security
Plaintext passwords must never be stored because database breaches expose user credentials. Hashing is a one-way mathematical function. We utilize werkzeug.security.generate_password_hash(), which applies salted cryptographic algorithms (scrypt:32768:8:1 or pbkdf2:sha256) to neutralize dictionary and rainbow-table attacks.
Q5 How was Task 4 (Automated Email Notification) engineered?
+
Task 4: Security Notification
Implemented in utils/email_service.py using Python's standard smtplib library. Connects to Gmail SMTP relay (smtp.gmail.com, port 587) with STARTTLS transport encryption. If login credentials match, a "Successful Login" confirmation is dispatched. If credentials fail, an urgent "Intrusion Alert" is dispatched. All events are logged into login_audit_logs.
Q6 How does the Razorpay Payment Gateway integration work?
+
Task 5: Payment Gateway
1. Order Initiation: Client selects package; Flask calls razorpay.Client.order.create() converting INR to paise.
2. Modal Checkout: checkout.js launches the official Razorpay popup for UPI / Card / Netbanking.
3. Signature Verification: Razorpay returns payment_id, order_id, and signature token. The backend verifies HMAC-SHA256 integrity before database persistence and generating digital tax invoices.
